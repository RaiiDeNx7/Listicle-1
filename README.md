# WEB103 Project 1 - *Listicle Part 1*

Submitted by: **Hunter Smith**

About this web app: **Virginia Music Venues is a web app that helps users discover live music venues across Virginia. The app displays venues in an easy-to-browse card layout with information such as location, venue type, capacity, and a description. Users can select a venue to view a detailed page and learn more about it. The app is built using Vanilla HTML, CSS, and JavaScript with Pico CSS for styling.**

Time spent: **2** hours
